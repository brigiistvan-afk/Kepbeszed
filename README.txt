Képbeszéd – telepíthető webapp (PWA)

Feltöltés GitHub Pages-re:
1. Hozz létre egy új repót (pl. kepbeszed).
2. Töltsd fel a mappa teljes tartalmát a repó gyökerébe (index.html, sw.js, manifest.webmanifest, icons/, p/).
3. Settings → Pages → Branch: main, mappa: / (root) → Save.
4. Pár perc múlva elérhető: https://<felhasználónév>.github.io/kepbeszed/

Telepítés telefonra:
- Android (Chrome): menü → "Telepítés" vagy "Hozzáadás a kezdőképernyőhöz".
- iPhone (Safari): Megosztás → "Főképernyőhöz adás".
Az első megnyitás után internet nélkül is működik.

Frissítés: minden új csomag automatikusan új verziószámot kap. Elég a fájlokat felülírni a repóban; a telefonokon az app a következő megnyitáskor magától frissül, kézzel semmit nem kell átírni.
